# Project Images

Place your project screenshot images in this directory.

## Required Images:

- `filateam.png` - FilaTeam project screenshot
- `seccodeid.png` - Landing Page Seccodeid screenshot
- `cilog.png` - CIlog project screenshot
- `blog-laravel.png` - Blog Laravel screenshot

## Recommended Image Specifications:

- **Format:** PNG or WebP
- **Dimensions:** 1200x630px (or 16:9 aspect ratio)
- **Size:** < 500KB (optimized)
- **Content:** Clear screenshot of the project home page or dashboard

## Tips:

1. Use high-quality screenshots
2. Remove any sensitive data before adding
3. Optimize images with tools like TinyPNG or ImageOptim
4. Consider using WebP format for better compression

If an image fails to load, a fallback gradient will be shown instead.
